Magazines & issues — clickable mockup

Vanilla HTML, no build. Click around inside the phone. The ← button walks a real back stack.

Try this path

  1. Library → tap the Magazines chip (issues appear as rows among books; the chip narrows to magazine titles).
  2. Tap National Geographic → series page with subscription badge and newest-first issues; a bound volume is one row.
  3. + Add issue → the form is prefilled with the next number/date from the frequency. Toggle Bound volume.
  4. Tap an issue → it is a normal catalogue item: lend, copies, location — all the existing item features.
  5. On Library, the FAB opens a sheet: Add book / Add magazine issue / New magazine.
  6. Magazines list: Frontline shows Expiring soon, Chandamama shows Lapsed (subscription tracking is optional per title).

Mapping to the plan

Issue row = Book with periodicalUid, volume, issueNumber, issueNumberEnd (bound), issueDate, issueLabel. Series page = Periodical entity. Badges come from SubscriptionStatus (30-day window).
