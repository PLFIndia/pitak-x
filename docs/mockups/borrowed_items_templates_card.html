Borrowed Items — "Message templates" as an expandable card

The message icon in the app bar disappears. What people actually do on this screen is pick which language/template goes out; add/edit/duplicate/delete is rare. So the card handles the common case inline (choose a template) and hands off the rare case to the existing full manager page. Click a card header to toggle.

Option A — Picker card: radio list inline, "Manage" link for the rest

Header shows the selected template name ("Reminder · Hindi"). Expanded: radio list of all templates, the unencrypted-storage note, and a Manage templates link to the existing page for add/edit/duplicate/delete. Selecting a radio saves immediately (that is already how the manager page works).

Option B — Chip picker: one row of language chips, card expands for details

Collapsed header is itself the picker: a horizontal row of template chips (English / Hindi / Marathi). Tapping a chip selects it — zero extra taps for the main job. Expanding shows the full text preview of the selected template with Edit / Duplicate / Delete (custom only), Add, and the storage note. The separate manager page becomes unnecessary and could be removed later.
