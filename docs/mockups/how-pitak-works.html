Put your catalogue online

Pitak can turn your book list into a simple public web page that anyone can open and search. It is free — the page is hosted by GitHub.

What goes online: titles, authors, covers, and — if your vault is unlocked when you publish — whether a book is available.
Never goes online: borrowers, loans, notes, shelf locations.

You need
A free GitHub account (github.com — two minutes)Internet

First time

  1. Open ☰ → Publish to web.
  2. Tap Sign in to GitHub. Pitak shows a short code.
  3. Open the link shown (github.com/login/device) — on this phone or on a computer — log in to GitHub and type the code. Come back to Pitak; it continues by itself.
  4. Tap Set up a repository, give it a short name like my-library, tap Create. (A repository is just the folder on GitHub that holds your page. Pitak creates it and switches the page on.)
  5. Tap Publish catalogue now.
  6. Your web address appears under Your site. Tap Copy link or Share. The first time, the page can take a minute or two to go live.

Every time after that

Added or lent books? Open Publish to web and tap Publish catalogue now again. Only what changed is uploaded, so it takes seconds.

Good to know

  • The Basic info tab adds your library's name, address, email and phone to the page. Every field is optional.
  • Signing out of GitHub does not take your page down.
  • Sign-in not finishing? Keep the code screen open and type the code in a browser on a computer instead.

Try it: the stub screen behind this button simulates sign-in, repository setup and publishing.

Put your library on the map

Other Pitak libraries that bookmark yours — by adding your web address (the GitHub Pages link Pitak created) to their Library network list — see it as a pin on their Library network › Map. Nothing is shown until you switch it on and publish — and you choose how exact the pin is.

Steps

  1. Find your coordinates: in Google Maps (or OpenStreetMap) press and hold on your library's spot. Two numbers appear, like 12.9716, 77.5946 — copy them.
  2. Open ☰ → Publish to web → Basic info and tap Edit.
  3. Paste the numbers into GPS location.
  4. Under Share my location on the network map pick Approximate (~1 km) or Exact. Tap Save.
  5. Back on Connection, tap Publish catalogue now. The pin travels with your page.
  6. Let other libraries save you: send them your site link (☰ → Share Library Website) or show them your card (☰ → Library network → My card). When they tap Refresh, your pin appears on their map.

How the map works

  • Your map shows only the libraries on your own Library network list — the ones you bookmarked, added as members, or that Pitak found through your hubs — and only those that publish a location.
  • Only web addresses made by Pitak can be bookmarked (they end in github.io or pages.dev). Other websites are not accepted.
  • Pin positions come from each library's published page, read when you tap Refresh. Nobody's location is sent anywhere else.

Good to know

  • Pitak never reads your phone's location. It publishes only the numbers you type.
  • Approximate rounds the pin to about 1 km — your neighbourhood, not your door.
  • To take the pin down, choose Not shared and publish again.

All of these live under ☰ → Settings → Data. Pick by what you want to do:

Bring that copy backRestore backup
Share or print my book listExport
Add books from a file (a Pitak export, a Goodreads CSV)Import
Combine another maintainer's Pitak library with mineMerge from a file

Backup — what is inside

Your books, wishlist, cover images, library identity and saved-libraries list, plus the borrowers vault if you have one (it stays encrypted and opens with the same passphrase).

Not inside: events and posters, logo, contact details, publishing setup, app settings — set those up again after a restore.

Keep the file somewhere private (your Drive, a computer) — it is your data in plain form, except the vault.

Make a backup

  1. ☰ → Settings → Data → Create backup.
  2. Tap Create backup and choose where to save the file.

Restore on a new phone

  1. Install Pitak → ☰ → Settings → Data → Restore backup.
  2. Tap Choose .pitabak file and pick it. Pitak shows what the file contains.
  3. If it contains a vault, enter that vault's passphrase. Tap Restore.

Restoring replaces this phone's books, wishlist, covers, identity and saved libraries with the backup's. It is all-or-nothing: if anything goes wrong, nothing changes.

Export vs backup

Export is for sharing: JSON keeps every detail and can be imported again; CSV opens in a spreadsheet; PDF is a printable catalogue (you pick the columns). A backup is for you: it is the only file that carries the vault and the covers.

Import adds to your library — nothing is deleted. A book that is already here is updated if it is the same Pitak book, or skipped if it has the same ISBN.

Good to know

  • Make a backup before a restore or a merge.
  • A backup that contains a vault replaces your current vault when restored.

Lending and the borrowers vault

The vault is Pitak's locked drawer: who borrowed which item, when it is due, and how to reach them. It is encrypted on this phone and opens only with your passphrase. Your catalogue is never locked — you can catalogue without opening the vault.

Set up once

  1. ☰ → Borrowers vault.
  2. Choose a passphrase of at least 8 characters and type it twice. Write it down somewhere safe — it is the only key. Pitak never stores it and cannot reset it.
  3. Optional: ☰ → Settings → Security → Biometric unlock to open the vault with your fingerprint or face from then on.

Lend an item

  1. Open the item and tap Lend. (Locked vault? Unlock it first.)
  2. Pick an Existing borrower, or type a New borrower name.
  3. Set a Due date if you want a reminder. Tap Lend.

Returns and reminders

  • ☰ → Borrowers vault, tap the borrower, tap Edit → Return next to the item.
  • The bell icon (Pending) on the vault screen lists overdue loans, loans due soon, and items missing details.
  • Add a phone or email on a borrower's page and you get Call, WhatsApp and Email buttons there.

Good to know

  • The vault stays open until you tap the lock icon or close the app — there is no timer. Lock it before handing your phone to someone.
  • Require biometric to open Pitak (Settings → Security) is a different thing: it covers the whole app with a prompt but does not encrypt anything. The vault is the encrypted part.
  • Your published page can show "available / on loan" — never who borrowed. It only does so if the vault was unlocked when you published.

Hubs, members and library cards

☰ → Library network is your list of other Pitak libraries. Nothing leaves your phone until you tap Refresh, which reads each library's published page.

What a hub is

A hub is a Pitak library that lists other libraries as its members — picture a wheel: the hub in the middle, the members as the spokes. Any library can be a hub; it only needs a published page, and it can have no books of its own.

Two examples

  1. A library association. The association sets up Pitak and publishes a page. At each meeting it scans a member library's card (Add member). The association's page lists every member; each member is asked once whether to show the membership, and after it says yes and publishes, its page points back to the association.
  2. A main library with branches. Each branch runs its own Pitak with its own page. The main library scans each branch's card. Its page lists all the branches; each branch's page points back to the main library.

The buttons

  • Add bookmark saves a library by its web address.
  • Add member scans another library's card, in person. That makes you a hub and lists them on your page as your member.
  • If a hub lists you, Pitak asks once: "show that you're a member of X?" Say yes and it appears on your page; say no and you are not asked again.
  • My card is your own card to show — it is your site address plus a public fingerprint, never your private library ID.
